# UMI LAB v0.2.10

Open object canvas with editable text documents, image/media imports, video/audio conversion, and optional 3D modelling.


Release 0.2.11 adds typed multimedia actions, source-preserving text/media imports, optional HLS playback and opt-in sharing. See docs/MEDIA_STUDIO.md.

### v0.2.18 — 3D imports and material editing
Drag GLB/FBX/OBJ/STL/PLY/DAE/USD models onto the canvas (Blender required for
non-GLB conversion). The 3D menu supports independent material ZIP export and
reimport, plus 1×–16× texture downscaling in **Optimise → Advanced**. Original
models are retained and output sizes are reported after processing.
